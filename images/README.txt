PUT YOUR MENU PICTURES HERE
---------------------------
1. Save each photo from the Omusubiya Facebook page (right-click > Save image as) into this folder.
2. Name the file after the menu item, lowercase with dashes:

     Salmon Onigiri       ->  salmon-onigiri.jpg
     Tuna Mayo Onigiri    ->  tuna-mayo-onigiri.jpg
     Umeboshi Onigiri     ->  umeboshi-onigiri.jpg
     Katsuobushi Onigiri  ->  katsuobushi-onigiri.jpg
     Iced Tea             ->  iced-tea.jpg

   (.jpg, .jpeg, .png, .gif are supported. Any size is fine; the system crops it to fit.)
3. Restart the system. Items without a photo show a drawn placeholder.

To add NEW menu items or change prices, edit menu.csv in the folder above.
